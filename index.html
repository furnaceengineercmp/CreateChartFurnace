Sumber Data

Pilih salah satu cara untuk memuat data: unggah file Excel, unggah/olah CSV, atau ketik & tempel (paste) data secara manual.

Klik untuk memilih file Excel (.xlsx / .xls)

Baris header akan terdeteksi otomatis dan langsung terbaca di grafik.

Klik untuk memilih file CSV

Jika data belum berbentuk tabel rapi (misalnya hasil unduhan Grafana), gunakan Text‑to‑Columns di bawah.

Klik pada sel pojok kiri‑atas lalu tempel (Ctrl+V / Cmd+V) data yang sudah di‑block dari Excel/sumber lain — semua sel akan terisi otomatis. Centang kotak di kolom paling kiri untuk memilih beberapa baris sekaligus, lalu klik "Hapus Baris Terpilih".

Pratinjau Data

Sel dapat diklik dua kali untuk diedit langsung. Tipe kolom (angka/tanggal/teks) terdeteksi otomatis.

Belum ada data dimuat.

Pengaturan Grafik

Klik "⚙️ Konfigurasi" pada tiap grafik untuk memilih sumbu, series, jenis grafik, rentang tanggal, dan sumbu Y. Klik titik data pada grafik untuk melihat callout nilai; klik lagi callout untuk menghapusnya.

Panel Korelasi Antar Data
