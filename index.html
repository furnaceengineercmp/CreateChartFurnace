Sumber Data

Pilih salah satu cara untuk memuat data: unggah file Excel, unggah/olah CSV, atau ketik & tempel (paste) data secara manual.

Klik untuk memilih file Excel (.xlsx / .xls)

Baris header akan terdeteksi otomatis dan langsung terbaca di grafik.

Klik untuk memilih file CSV

Jika data belum berbentuk tabel rapi (misalnya hasil unduhan Grafana), gunakan Text‑to‑Columns di bawah.

Klik pada sel pojok kiri‑atas lalu tempel (Ctrl+V / Cmd+V) data yang sudah di‑block dari Excel/sumber lain — semua sel akan terisi otomatis. Centang kotak di kolom paling kiri untuk memilih beberapa baris sekaligus, lalu klik "Hapus Baris Terpilih".

Tabel dengan 2 baris header (sel merge) + baris Target: di Excel, block seluruh tabel mulai dari baris header paling atas, lalu di sini klik sel header paling kiri (baris "Kolom 1") dan tempel (Ctrl+V). Baris 1 = header grup, baris 2 = sub-header, dan baris yang diawali tulisan "Target" otomatis menjadi baris target/standar (mis. >22%, <0,37%, 680-750). Jika tabel hanya 1 baris header, tempel dengan cara yang sama.

Pengaturan Grafik

Klik "⚙️ Konfigurasi" pada tiap grafik untuk memilih sumbu, series, jenis grafik, rentang tanggal, dan sumbu Y. Klik titik data pada grafik untuk melihat callout (pilih gaya "Lengkap" atau "Angka saja"); klik titik yang sama lagi untuk menghapusnya. Tombol "🔢 Angka Semua" menampilkan angka di semua titik. Data & susunan grafik tersimpan otomatis di browser ini; gunakan "💾 Simpan Proyek" di atas untuk membuat file cadangan .json.

Panel Korelasi Antar Data

Bandingkan dua kolom data numerik dari tabel yang sama untuk melihat apakah keduanya berkorelasi, berdasarkan nilai koefisien korelasi (R).

Geser (lag): untuk data yang efeknya tertunda. Contoh geser +1 = data A hari ini dipasangkan dengan data B 1 baris sesudahnya (mis. Calcine Consume hari ini vs FeNi Packed besok). Geser −1 = data B diambil 1 baris sebelumnya. Satu baris = satu hari jika data Anda harian dan berurutan; pilih kolom tanggal di atas agar data diurutkan dulu.
